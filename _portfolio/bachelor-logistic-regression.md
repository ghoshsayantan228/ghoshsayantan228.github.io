## Overview

A Bachelor's project in Statistics focused on identifying health parameters
associated with diabetes among women and developing a logistic regression
model using health-related variables.

## Analysis

- Analysed a dataset of 376 women across 8 variables.
- Explored seven health parameters using descriptive statistics and
  comparative visualizations.
- Fitted a generalized linear model with a logit link for the binary diabetes
  outcome.
- Evaluated predictor significance and compared model specifications using
  AIC and residual deviance.
- Removed less-contributing variables to obtain an optimized model.

## Key Findings

The final model identified pregnancies, glucose level, blood pressure, insulin,
BMI and diabetes pedigree function as significant predictors in the dataset.
