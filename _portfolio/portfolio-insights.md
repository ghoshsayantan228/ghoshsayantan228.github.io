## Overview

A personal analytics application for tracking equity investments, monitoring portfolio performance and exploring historical investment data through an interactive dashboard.

## What I Built

- Built the application in Python using Pandas for data processing and transformation.
- Calculated portfolio-level performance metrics from investment data.
- Developed interactive visualizations using Plotly.
- Created a Streamlit interface to make the analysis accessible through a web application.

## Technologies

**Python · Pandas · Streamlit · Plotly · Data Analysis**
